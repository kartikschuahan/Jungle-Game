# 🌴 Jungle Game - A Fun Adventure! 🏕️

Welcome to the **Jungle Game**! 🌿🐍 You are lost in the middle of a dense jungle, and your only goal is to **find a way out**! But beware, the jungle is full of surprises! Can you make the right choices and **escape safely**? 🏃‍♂️💨

---

## 🎮 How to Play?
1️⃣ Run the script in **Python** 🐍.
2️⃣ You will be prompted to enter your name.
3️⃣ You have to make choices by typing **Left, Right, Help, or Own way**.
4️⃣ Each decision takes you to a new situation. Choose wisely! 🤔
5️⃣ If you find the right path, **you win!** 🏆

---

## 📝 Game Rules
✅ Choose your path carefully.
✅ Type your choices exactly as given (e.g., "Left" or "Right").
✅ Some choices will lead to **dangerous situations** like falling into a pit or getting bitten by a snake! 🐍😨
✅ Ask for **help** to escape successfully! 🚁

---

## 💻 Requirements
- Python 3.x
- Basic understanding of running Python scripts
